Última prueba guardada: Ninguna todavía.

1. Probar el guardado

El botón actualiza únicamente el registro de prueba y conserva los demás textos que pudieras haber importado.

2. Copia de seguridad

Descarga una copia JSON con un control de integridad SHA-256. Consérvala fuera del navegador para poder recuperar tus datos.

3. Recuperar una copia

Antes de escribir, el archivo se comprueba íntegramente y se solicitará confirmación. Si algo falla, no se sustituye el corpus actual.
